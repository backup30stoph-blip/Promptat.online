# Security & Performance Headers

## Directives
Configure and review security recommendations:
* **CSP (Content Security Policy)**: Safe origin domains.
* **HSTS (HTTP Strict Transport Security)**: Force SSL.
* **X-Frame-Options**: Prevent clickjacking inside third-party frames.
