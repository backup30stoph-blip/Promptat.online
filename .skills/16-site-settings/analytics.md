# Analytics Integration & Script Blocks

## Google Analytics 4 (GA4)
Supports dynamic injection of tracking libraries with options:
* **Measurement ID** (`G-XXXXXXXXXX`)
* **Anonymize IP**: Toggles privacy-compliant tracking
* **Debug Mode**: Allows real-time analysis
* **Consent Mode**: Restricts tracking based on cookie consent cookies
* **Enhanced Measurement**: Automatically tracks pageviews, scroll events, outbound clicks, and search behavior.
* **Cross Domain Tracking**: Sets up domain linkers.
