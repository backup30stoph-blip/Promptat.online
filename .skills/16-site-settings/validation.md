# Search Settings Validation

## Checks
* **Robots Syntax validation**: Ensures no invalid characters or incorrect Disallow syntax.
* **Redirect Loop detection**: Warns user if `/a` redirects to `/b` while `/b` redirects to `/a`.
* **Broken Links detection**: Evaluates 404 logs to identify missing URL matches.
