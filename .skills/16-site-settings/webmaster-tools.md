# Webmaster Tools & Verification Verification Codes

## Verification Metatags
Support injection of the following site verifications into the `<head>` of the main page dynamically:
* `google-site-verification` (Google Search Console)
* `msvalidate.01` (Bing Webmaster Tools)
* `p:domain_verify` (Pinterest Verification)
* `yandex-verification` (Yandex Webmaster)
* `baidu-site-verification` (Baidu Webmaster)
* `facebook-domain-verification` (Facebook Domain Verification)

These are managed via the Site Settings admin dashboard and stored in the `site_settings` table.
